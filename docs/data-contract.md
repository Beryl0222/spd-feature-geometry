# 正定矩阵的坐标与几何
资料中的矩阵已是合成协方差，项目不估计原始传感器统计。channel_ids及单位必须一致；每站给可逆B，物理矩阵C=B*C_local*B^T。缺通道不可补零。矩阵需对称误差<=1e-10、lambda_min>=1e-6且cond2<=1e6，允许合法重根。模型计算用float64。
几何距离d(C,D)=||log(C^(-1/2)*D*C^(-1/2))||F。参考M最小化sum(w_i*d(M,C_i)^2)/sum(w_i)，合格窗口至少3条不同record_id且正权重；修订替换旧记录，撤回不再有权重。均值残差为||sum normalized(w_i)*log(M^(-1/2)*C_i*M^(-1/2))||F，接受上限1e-7；迭代额度由请求给出。封口才可发布。归一化T=log(M^(-1/2)*C*M^(-1/2))，输出Y=gamma*T+Beta，其中gamma为标量，Beta对称；查询的度量直接用同物理坐标矩阵之间的d，切空间欧氏差只作为同参考的显式查询模式，二者要在结果中区分。
联合训练请求声明参考可训练与否：冻结时只对C/gamma/Beta回传，联合时需把M最优条件的隐式依赖传到有效校准C及其非负权重；不对record身份、封口、拒绝条件求导。上游余量是对Y的实数矩阵，输入对称参数以全矩阵Frobenius内积解释，返回对称VJP。几何均值非收敛或伴随残差>1e-6时相应站点不计训练分母。样本权重按合格站点有效样本归一，空窗不更新。
描述子记录原矩阵身份、物理坐标变换及参考代次；若可在某共同有效参考上复算，允许继续比较，不能仅改代次标签。无原矩阵且原参考不能逆解释时标不可比。新参考失败时原有效参考仍可用，但一条联合损失中不能混用同站新旧解释。共同基变换下d应在rtol1e-5内相同；归一化切空间元素不要求逐元素不变。数值atol1e-7/rtol1e-5，内点梯度rtol5e-4。CPU维2至16，每站最多64校准矩阵、8站、最多2048描述子，活动矩阵与工作区总32MiB。
